### 📌 Featured Projects

#### 🏠 Homelab Media & Security Stack
A self-hosted media stack on Proxmox with a security-first approach: Zero-Trust remote access (Tailscale), VPN kill switch (Mullvad), and automated malware scanning (ClamAV).
- **Tech:** Proxmox, LXC, Tailscale, WireGuard, ClamAV, Docker
- **[View Repository](https://github.com/MirisanCatalin/homelab-media-security-stack)**

#### 🎯 Active Directory Attack Lab (In Progress)
An isolated lab for practicing AD attack paths and defensive hardening using GOAD and BloodHound.
- **Tech:** Active Directory, GOAD, BloodHound, Impacket
- **[Coming Soon]**

#### 🔐 Secure Deduplicated Sync (Bachelor's Thesis — In Progress)
A synchronized and secure storage system with data deduplication, exploring applied cryptography for secure dedup and efficient incremental sync.
- **Focus:** Convergent encryption, content-defined chunking, integrity verification, threat modeling
- **Status:** 🚧 In progress — repo will be public after thesis defense
- **Expected tech stack:** Python, cryptography.io, SQLite (to be confirmed)
